# Xedats-Standalone

Standalone home for the Xedats runtime package and its optional Xedats-specific console module.

## Repository layout

- `packages/Xedats` - standalone Xedats runtime package with internal singleton bootstrapping
- `packages/XedatsConsoleModule` - optional Xedats-specific command bridge for a compatible host console
- `docs/package-matrix.md` - package overview and suggested ways to use the repository

## Notes

- Package-level READMEs remain the source of truth for package-specific setup steps.

## Project Bundle

If you want the pre-bundled setup with the wider tool stack already wired together, use: `https://github.com/XenoLoaf/Xedats_ProjectBundle`
